# gmsg: Python runtime of GMP

The runtime package of the Python code generated by [GMP](../README.md) (`gmpc --lang python`), for Python 3.12 and later.
It is a port of the C++ runtime with the same behaviour and output: checksums and CRCs, framing and byte stuffing,
the stream parser with resync / flush / idle recovery, strict number parsing, exact float text (the results of
`std::to_chars` / `std::from_chars`) and the human-readable printer.

```sh
pip install ./runtime-py          # from the GMP repository; builds the accelerator when a C compiler is available
```

Without installing, put `runtime-py` on `sys.path` / `PYTHONPATH`. The package has no dependencies.

## Accelerator

`gmsg._native` is an optional C extension built from `native/_native.c` and the header-only C runtime
(`runtime-c/include`; set `GMSG_C_INCLUDE` when building outside the repository). It uses only the CPython limited API,
so one abi3 binary serves CPython 3.12 and later. It speeds up checksums (CRC-32: about 50x), frame scanning, escaping,
number parsing and float text (text protocols: 2 to 2.5x); binary message fields stay Python code.

- It is used automatically when present. `gmsg.NATIVE` tells whether it is in use.
- `gmsg.use_native(False)` or the environment variable `GMSG_PURE=1` turns it off.
- `GMSG_PURE_INSTALL=1 pip install ./runtime-py` installs the pure-Python package only.

The API and every result are the same with and without it; the GMP test suite runs everything both ways.

## Modules

| module | contents |
|--------|----------|
| `gmsg.errors` | `Err` (IntEnum, same codes as `gmp::Error`), `GmpError`, `fail`, `error_text` |
| `gmsg.core` | `Reader`, `Writer`, integer checks and C++ conversions, bit fields, `to_f32` |
| `gmsg.checksum` | presets (`crc32`, `crc16_ccitt`, `xor8`, ...), `crc(width, poly, ...)`, `PRESETS` |
| `gmsg.framing` | escape configurations, `FrameScan`, `scan_fixed` / `scan_length_prefixed` / `scan_delimited` |
| `gmsg.stream` | `StreamParser`, `Received`, `StreamStats`, `extra_of` |
| `gmsg.text` | token splitting, `parse_int` / `parse_float`, `TextWriter` |
| `gmsg.floattext` | `format_float`, `format_general`, `parse_float` |
| `gmsg.printer` | `Printer`, `to_text` |
| `gmsg.gen` | support of generated code: `GmpEnum`, `Opened`, `FieldRange`, `TextField`, helpers |

Everything is also available from `gmsg` directly.
